# 日本株 損益・リスクシミュレーター

利用者が手入力した日本株の基準株価・保有情報から、現在の評価損益、固定下落率別の想定損益、最大損失許容額への到達株価を可視化するWebアプリです。

## 主な機能

- 銘柄コードと市場を指定し、サーバー経由でOpenFIGIから銘柄名候補を取得
- API障害・該当なし・レート制限時も、会社名の手入力または「名称未取得」で試算を継続
- ローカル・非公開の個人利用に限り、J-Quants V2の約12週間遅延終値を任意で入力欄へ反映
- 入力価格基準の評価損益と、5%・10%・15%・20%・30%下落時の試算
- 最大損失許容額の超過判定と到達株価
- レスポンシブなグラフ、PC用テーブル、モバイル用カード
- 項目単位の入力検証、古い可能性がある価格基準日の注意表示
- 入力内容は永続保存しません

## ローカル起動

Node.js 20.19以上を使用してください。

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43127
```

`http://localhost:43127` を開きます。OpenFIGIはAPIキーなしでも利用できます。任意で `OPENFIGI_API_KEY` をサーバー環境変数に設定すると、認証情報をブラウザへ露出せずにキー付きリクエストを行います。

## J-Quants任意連携（ローカル・非公開のみ）

J-Quants API V2は、ダッシュボードで発行したAPIキーを `x-api-key` ヘッダーへ付ける方式です。V1のIDトークン・リフレッシュトークン方式は廃止されています。Freeプランは約12週間遅延し、利用期間は1年間です。

J-Quants APIは個人の私的利用に限定されます。個人資格のデータを第三者が閲覧できる公開デモ、法人利用、運営者サーバーでの第三者向け中継・蓄積には使用できません。この実装は次の防御を設けています。

- 既定は無効。未設定・取得失敗時は既存の株価手入力へフォールバック
- `localhost`、`127.0.0.1`、`::1` からのリクエストだけを許可
- APIキーはサーバー環境変数だけで読み、レスポンス、ログ、ブラウザバンドルへ含めない
- 取得値を保存・キャッシュせず、利用者の画面内で入力値としてのみ利用
- J-Quantsが収録する東証銘柄だけを対象とし、OpenFIGIの市場選択がTSEの場合に限る

個人のローカル環境でのみ、`.env.example` を `.env.local` へコピーし、次を設定します。秘密値をコミットしないでください。

```dotenv
JQUANTS_PRIVATE_MODE=true
JQUANTS_API_KEY=J-Quantsダッシュボードで発行したAPIキー
```

公開・共有環境では `JQUANTS_PRIVATE_MODE=false` のままにします。画面の「遅延終値を入力欄へ反映」は取得できない旨を表示し、基準株価・基準日は引き続き手入力できます。

## データについて

既定では株価を自動取得しません。利用者が信頼できる情報元で確認した価格を入力してください。J-Quants任意連携を有効にした場合も、約12週間遅延した参考値であり現在値ではありません。銘柄名候補はOpenFIGIから取得しますが、名称の正確性は保証されません。外部サービスや秘密情報がなくても、手入力による全計算機能を利用できます。

本アプリは試算ツールであり、投資成果の保証や売買の推奨を行うものではありません。税金、売買手数料、配当、株主優待、信用取引金利は計算に含みません。株式分割・併合がある場合は、調整済みの平均取得単価を利用者自身で入力してください。
