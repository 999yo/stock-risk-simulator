# 日本株 損益・リスクシミュレーター

手入力した株価、または個人利用のデプロイ先で取得した約12週間遅延の終値と、保有情報から、評価損益、固定下落率別の想定損益、最大損失許容額への到達株価を可視化するWebアプリです。

## 主な機能

- 銘柄コードと市場を指定し、サーバー経由でOpenFIGIから銘柄名候補を取得
- API障害・該当なし・レート制限時も、会社名の手入力または「名称未取得」で試算を継続
- 株価は常に手入力でき、取得値も上書きできる
- 個人利用のデプロイ先では、localhostに限らず、サーバーがJ-Quants API V2無料版の約12週間遅延終値を取得し、株価と価格基準日へ反映する
- APIキー未設定・取得失敗時は手入力で試算を続行する
- この株価での評価損益と、5%・10%・15%・20%・30%下落時の試算
- 最大損失許容額の超過判定と到達株価
- レスポンシブなグラフ、PC用テーブル、モバイル用カード
- 項目単位の入力検証。手入力で価格基準日が古い場合の注意表示
- 入力内容は永続保存しません

## ローカル起動

Node.js 20.19以上を使用してください。

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43127
```

`http://localhost:43127` を開きます。OpenFIGIはAPIキーなしでも利用できます。任意で `OPENFIGI_API_KEY` をサーバー環境変数に設定すると、認証情報をブラウザへ露出せずにキー付きリクエストを行います。

## J-Quants連携（個人利用のデプロイ）

J-Quants API V2は、ダッシュボードで発行したAPIキーを `x-api-key` ヘッダーへ付ける方式です。V1のIDトークン・リフレッシュトークン方式は廃止されています。Freeプランの株価は約12週間遅延し、利用期間は1年間です。現在値でも12時間遅延でもありません。

APIキーの置き場所はサーバー環境変数 `JQUANTS_API_KEY` だけです。ブラウザ、ログ、レスポンス、Gitへ出しません。接続先がlocalhostかどうかでは有効・無効を切り替えません。個人の私的利用に限り、不特定多数への価格の再配信や非公式スクレイピングは行いません。

- キー未設定・取得失敗時は株価の手入力で試算を続ける
- 取得値は保存・キャッシュせず、同じ利用者の株価と価格基準日へ反映するだけ
- 反映した終値を上書きしていなければ「約12週間遅延の終値」と価格基準日を表示する
- 手入力、または取得値の上書き後は「利用者入力」と価格基準日を表示する
- J-Quantsが収録する東証銘柄だけを対象とし、市場がTSE以外のときは手入力へ案内する

個人利用のサーバーで使うときだけ、環境変数 `JQUANTS_API_KEY` にダッシュボードで発行したキーを設定します。値はリポジトリに書かないでください。`.env.example` に秘密値はありません。

## データについて

株価は手入力するか、サーバー環境変数にAPIキーがあるときだけ約12週間遅延の終値を反映します。その終値は現在値ではありません。銘柄名候補はOpenFIGIから取得しますが、名称の正確性は保証されません。外部サービスや秘密情報がなくても、手入力による全計算機能を利用できます。

本アプリは試算ツールであり、投資成果の保証や売買の推奨を行うものではありません。税金、売買手数料、配当、株主優待、信用取引金利は計算に含みません。株式分割・併合がある場合は、調整済みの平均取得単価を利用者自身で入力してください。
