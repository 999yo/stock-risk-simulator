# 日本株 損益・リスクシミュレーター

公開サイト: https://stockpl.vercel.app

保有している日本株について、今の評価損益と、株価が下がったときの損失を確認するWebアプリです。売買の推奨や、将来の株価予測は行いません。

## このアプリで確認できること

銘柄コードと市場を指定すると、会社名の候補を取得します。株価は手入力でき、個人利用の環境では約12週間遅延の終値を入力欄へ反映することもできます。反映した値は上書きできます。

入力した株価、平均取得単価、保有株数、最大損失許容額から、次を計算します。

- 取得総額、評価額、評価損益、損益率
- −5%から−80%まで、10段階の下落後の株価と想定損益
- 最大損失許容額に到達する株価と、そこまでの下落率

PCでは結果を表、スマートフォンではカードで表示します。

## 設計で意識したこと

日本株の価格を、無料のまま公開アプリへ自動配信できる公式な手段は確認できませんでした。証券サイトや非公式APIからの収集は、利用規約と停止リスクがあるため採用していません。

無料で公式に使えるJ-Quants APIは、約12週間遅延の終値です。画面には「約12週間遅延の終値」と基準日を表示し、現在値とは区別しています。APIキーはサーバーの環境変数だけに置き、ブラウザとGitには出しません。

キーが未設定のとき、または取得に失敗したときは、入力済みの株価を消さずに手入力で試算を続けられます。価格が取れなくても、損益計算という主要機能が止まらない構成にしています。

計算ロジックは自動テストで確認しています。税金、手数料、配当、株式分割後の取得単価調整は含めていません。分割や併合がある場合は、調整済みの平均取得単価を利用者が入力します。

## 技術構成

- Next.js（App Router）
- TypeScript
- Tailwind CSS
- shadcn/ui
- Vitest

会社名の候補は OpenFIGI、遅延終値は J-Quants API V2 を、いずれもサーバー側から取得します。

## ローカルでの起動

```bash
npm install
npm test
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

約12週間遅延の終値を使う場合だけ、`.env.local` に次を設定します。このファイルはGitへ含めません。

```bash
JQUANTS_API_KEY=発行したAPIキー
```

## 現在の対象範囲

1回の試算は1銘柄です。入力内容の保存、ログイン、複数銘柄の管理は、この版には含めていません。
