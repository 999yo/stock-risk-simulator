# 日本株 損益・リスクシミュレーター

保有株の評価損益と、自分で決めた損失額を超える株価を、その場で試算するWebアプリです。公開デモでは株価を自動取得せず、入力した価格だけで計算します。

## できること

- 銘柄コード、市場、株価、株数、平均取得単価、最大損失許容額から試算する
- いまの評価損益と、5%・10%・15%・20%・30%下落したときの想定損益を見る
- 最大損失許容額に到達する株価を出す
- 銘柄名の候補をOpenFIGIから取得する。取れないときは会社名を手入力するか、名称なしで続ける
- 株価はいつでも手入力でき、取得した値も上書きできる
- 入力は保存しない。PCでは表、狭い画面ではカードとグラフで見る

## 株価をスクレイピングしない理由

Yahoo Finance や株価サイトの画面・非公式APIを自動取得すると、各社の利用規約が禁じる収集になりやすく、東証の相場情報を不特定多数へ見せる再配信の問題も残ります。採用や実績紹介のための公開サイトは、無料でも第三者への表示にあたります。出典や「参考値」の注記では解消できないため、非公式スクレイピングはせず、公開デモでは価格を配信しません。

## 無料の自動取得が約12週間遅延の終値である理由

個人の私的利用に限って、公式の [J-Quants API V2](https://jpx-jquants.com/ja/spec/eq-bars-daily) 無料版から終値を取れます。無料版の株価は約12週間遅延で、現在値でも12時間遅延でもありません。アプリはその期間だけを問い合わせ、調整後終値があればそれを円単位で使います。この終値を公開サイトで第三者へ再配信することはしません。

## 未設定・失敗時に手入力へ戻す理由

試算そのものに外部の株価は不要です。APIキーがない公開デモ、認証失敗、利用上限、通信失敗、東証以外、終値が見つからない場合でも、計算を止めず、利用者が入れた株価で続けます。公開サイトはキーを置かないので、最初から手入力です。

## APIキー

`JQUANTS_API_KEY` と任意の `OPENFIGI_API_KEY` は、サーバーの環境変数だけに置きます。ブラウザ、レスポンス、ログ、Git、公開デモには置きません。公開デモの本番環境には `JQUANTS_API_KEY` を設定しません。個人の私的利用で遅延終値を使うときだけ、自分のサーバーにキーを設定します。名前だけの見本は `.env.example` にあります。秘密値はリポジトリにありません。

## 自動テスト

評価損益、固定下落率の想定損益、損失許容額への到達株価、約12週間の取得窓と終値の選び方は Vitest で自動テストしています。

```bash
npm test
npm run lint
npm run build
```

## ローカル起動

Node.js 20.19 以上。

```bash
npm install
npm run dev -- --hostname 0.0.0.0 --port 43127
```

http://localhost:43127 を開きます。キーがなくても、手入力ですべての計算が使えます。

## 注意

投資成果の保証や売買の推奨ではありません。税金、手数料、配当、信用取引の金利は含みません。株式分割・併合があるときは、調整済みの平均取得単価を自分で入れてください。
